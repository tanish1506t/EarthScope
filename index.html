ⓘ NASA POWER API Integration

Prediction Of Worldwide Energy Resources v2

Primary Endpoints: https://power.larc.nasa.gov/api/temporal/monthly/point

Model Provenance: Goddard Earth Observing System (GEOS) FP-IT atmospheric reanalysis with MERRA-2 assimilation.

Tracked Parameters:

  • T2M: Air Temperature at 2m (°C, daily/monthly mean)
  • T2M_MAX / T2M_MIN: Diurnal thermal extremes (°C)
  • PRECTOTCORR: Corrected precipitation (mm/day rate converted to mm/month)
  • RH2M: 2m Relative Humidity (%)
  • TS: Earth Radiative Skin Temperature (°C)

Quality Control & Ethics

Zero data fabrication protocol

Missing Values Protocol: NASA fill values (-999.0) are strictly quarantined as NaN and excluded from sums or variances. Values are never converted to zero.

Precipitation Normalization: Missing days threshold enforced; monthly precipitation is scaled by calendar days.

Dual-Method Hypothesis Testing: Both parametric OLS regression and non-parametric Mann-Kendall with Sen's slope are computed to prevent false positives from outliers.

EarthScope is an open-source, full-stack Earth science investigation platform designed to empower citizens, students, and researchers to investigate planetary environmental trends using genuine NASA observation data.

Instead of presenting static headlines, EarthScope treats the user as an active planetary trend detective—exploring multi-decadal records, testing hypotheses with rigorous statistics, and identifying extreme climate anomalies.
